# Nickolas Maia - Portfolio

Modern portfolio website built with Next.js, Tailwind CSS, Framer Motion, and Lucide icons.

## Overview

This repository contains the personal portfolio of Nickolas Maia de Araujo (`nickolss`), focused on:

- Fullstack development (Java, Spring Boot, TypeScript, React)
- DevOps learning track (Docker, Kubernetes, Grafana, Ansible)
- Highlighted projects in an animated Bento Grid layout

## Tech Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide React
- TypeScript

## Featured Projects

- Mirai
- Second Vision
- Personal RAG
- Front Sistema HAE
- Back Sistema HAE
- ArchWizard
